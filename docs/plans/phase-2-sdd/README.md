# Phase 2 subagent-driven-development records

Verbatim copies of the working files from the phase-2 build (2026-10-24). The summary and the decision table are in [`../2026-10-24-phase-2-record.md`](../2026-10-24-phase-2-record.md).

| File | Contents |
|---|---|
| `ledger.md` | The progress ledger: pre-flight scan, every ruling (R1–R38) with reasoning and cost if wrong, every review outcome, fix round, deferred minor and parked item, in order |
| `task-reports/task-N-report.md` | Each implementer's report: what was built, TDD evidence (red/green), deviations from the plan, fix-round reports |
| `final-findings.md` | Final whole-branch review findings and the binding rulings for the fix wave |
| `final-fix-report.md` | The fix wave's report, with before/after in-sample numbers |
| `constraints.md` | Global constraints handed to every reviewer |
| `implementer-rules.md`, `reviewer-rules.md`, `rereview-rules.md` | The process rules given to implementers and reviewers |

Paths in these files that start with `/home/pol/...` or `/tmp/...` refer to the build machine; scratch scripts under `/tmp` are not kept. The task briefs (verbatim plan text) and diff packages (reproducible from git) were not copied.
