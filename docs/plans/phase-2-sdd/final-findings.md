## I1 / R33 — fundamentals not truncation-invariant on real data
src/analyzer/data/edgar/quarters.py `_prefer`/`_one_per_quarter` rank "direct beats derived" above filing date; panel/fundamentals.py feeds that to quarter_steps. HAIN: Q 2015-04-01..06-30 is derived from the FY2015 10-K (filed 2015-08-21) but a restated FY2016 10-K (filed 2017-06-22) reports it directly, so with full data the quarter is known only in 2017; TTM breaks and falls back to stale annual from 2015-11 to 2016-05. Also WDC 2018. Reviewer measured ~3% of symbols affected at any cut.
Ruling: the point-in-time path keeps every candidate quarter (direct and derived) with its own filed date (do not change discrete_quarters' default behaviour used by audit; add a parameter or a new function, e.g. `quarter_candidates(df)`), and quarter_steps processes candidates by filed date so the earliest-known value is used first and a later candidate replaces a quarter's value only from its own filed date (quarter_steps already merges period ends within SAME_QUARTER_DAYS into one key). Add an opt-in real-database truncation test (new pytest marker `realdb`, deselected by default like `live`, skipped if data/analyzer.db is missing; open the DB read-only via a copy into tmp of the needed rows or `?mode=ro`): evaluate on ~50-120 real symbols full vs cut at 2-3 dates and assert rows up to each cut are identical. Run it once and report the result.

## I2 / R34 — YoY pairs wrong periods
features/quality.py uses x.shift(252) for "one year earlier"; on real data 10.5% of company-days compare periods not ~1 year apart (3.2% compare a period with itself). Touches gate 3 (revenue growth, margin, FCF trend, ROE), sub-scores, and the position plan's thesis stop.
Ruling (supersedes plan decision 4): steps emit year-earlier values: quarter path `ttm_ly` = sum of the four consecutive quarters ending ~365 days before q0 (reuse _year_ago tolerance), annual path = prior fiscal year value, carried through combine_ttm; instant path `avg5_ly` (average of the balance-sheet dates ending ~1 year before the latest). New panel fields `<prefix>_ttm_ly` for revenue, operating_income, net_income, eps, ocf, capex, da; `equity_avg_ly`. Age them like their TTM fields (value_filed). quality_features uses them instead of shift(year): revenue_growth, eps_growth, margin_change (margin_ly = op_ly / rev_ly), fcf_prev (ocf_ly - capex_ly), roe_change (ni_ly / equity_avg_ly). Keep float32. Truncation invariance preserved; tests for a known YoY pair and for "no same-period comparison".
